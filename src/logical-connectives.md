# Logical Connectives

The binary logical connectives are as follows:

| Logical Operation             | Grammatical Conjunction |
| :---------------------------- | :---------------------- |
| conjunction (ᴀɴᴅ)             | {sɪ}                    |
| disjunction (ᴏʀ)              | {zov}                   |
| exclusive disjunction (xᴏʀ)   | {drað}                  |
| material implication (ɪᴍᴘʟʏ)  | {ŋaz}                   |
| material biconditional (xɴᴏʀ) | {juθ}                   |

> [!note]
>
> Binary logical connectives are the only true grammatical conjunctions in
> Najan. Other semantic relationships between phrases or clauses are expressed
> using [prepositional phrases](./prepositional-phrases.md).

There is one unary connective, {txə}, which indicates logical negation (ɴᴏᴛ).

The logical constants ᴛʀᴜᴇ and ꜰᴀʟꜱᴇ, which can be considered nullary logical
connectives, are expressed using the verbs {jʊ} and {txəy}, respectively.
